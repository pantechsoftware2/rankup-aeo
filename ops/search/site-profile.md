# RankUp AEO site profile

As of 2026-09-23. Evidence is from the repository and the public production homepage; private analytics and hosting access were not available.

## Identity and offer

- Business: RankUp AEO.
- Site: https://www.rankupaeo.com
- Offer: SEO and AEO visibility audits, deeper reports, and 90-day implementation retainers.
- Audience: businesses with an existing website seeking qualified discovery through Google and AI answer engines.
- Primary conversion: free visibility audit, then custom report and strategy call.
- Stated retainer starting price: $7,500/month, shown on the public homepage; treat as a business claim, not an independently verified price.
- Languages: English.
- Stated markets: worldwide, with United States and India named in organization metadata.

## Stack and publishing

- Next.js 14 App Router, TypeScript/JSX, static generation for public marketing/content routes.
- Content source: `lib/blog.ts` and `lib/landing-pages.ts`; no CMS or MDX was found.
- Public generated routes: robots, sitemap, RSS feed, `llms.txt`, and `llms-full.txt`.
- Hosting/deployment documentation identifies Vercel; project ID and deployment credentials were not available.
- Build command: `npm.cmd run build`; lint command: `npm.cmd run lint`.

## Verified public structure

- Four blog posts, four service pages, and four industry pages are generated by the current build.
- Homepage links to services, industries, about, methodology, blog, contact, and audit flow.
- Sitewide Organization and WebSite JSON-LD is present; page templates add WebPage, Service, FAQPage, Article, ItemList, ContactPage, AboutPage, and BreadcrumbList markup as applicable.
- `robots.ts` allows public content and disallows API, review, report-preview, and onboarding paths.
