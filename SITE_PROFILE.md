## 7. Notes For Weekly SEO Runs

- Use the Next metadata API and `lib/seo.ts` helpers for titles, descriptions, canonicals, Open Graph, Twitter cards, robots metadata, and JSON-LD.
- Use `lib/blog.ts` for blog additions and `lib/landing-pages.ts` for service or industry landing page additions.
- Update `app/sitemap.ts` if a new important route is not automatically included through blog or landing page data.
- Run `npm.cmd run build` on Windows. The build may need network access because `app/layout.tsx` uses `next/font/google` for Inter and Space Grotesk.
